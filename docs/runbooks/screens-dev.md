# 画面を手元で確かめる

サーバーや本物のデータが無くても、偽の応答で 3 画面（スキル一覧・スキルの詳細・つなぎ方）を開ける。

## 起動

```sh
VITE_MOCK_API=1 bun run dev
```

- ポートは `.dev.vars` の `DEV_PORT` で決まる。無ければ 5173。
- 偽の応答は開発中だけ読み込まれる。本番のビルドには入らない。
- `VITE_MOCK_API=1` を付けないと、本物のサーバーを呼びに行く。

## 開く画面

| 画面             | パス                     | 見るところ                                              |
| ---------------- | ------------------------ | ------------------------------------------------------- |
| スキル一覧       | `/`                      | 7 件のカード。検索欄に合わない言葉を入れると 0 件の表示 |
| スキルの詳細     | `/skills/<スキル名>`     | ファイル一覧・プレビュー・使い方（claude.ai タブ）      |
| Claude Code 専用 | 「動画の字幕入れ」の詳細 | 専用の案内が出る                                        |
| つなぎ方         | `/connect`               | 手順の表示                                              |

スマホ幅の見え方は、ブラウザの幅を 390px にして確かめる（PC 幅は 1280px）。

## 変更後の点検

```sh
bun run lint:all
bun run typecheck
bun run test
```
