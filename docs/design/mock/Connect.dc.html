Claude とつなぐ

つなぎ方（最初の 1 回だけ）

  1. claude.ai を開き、「設定 › コネクタ」で「カスタムコネクタを追加」を押す
  2. 名前に「teamskill」、URL に上の URL を貼って追加する
  3. 「連携」を押し、いつもの Google アカウントでログインする

claude.ai でつなげば、同じアカウントの Claude Code からも使えます。
